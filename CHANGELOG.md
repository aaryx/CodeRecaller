# Changelog

## 0.2.0 — unreleased

* Metadata enrichment preserves identity, schedule and user-edited documentation.
* Durable generated-file/state transactions with validated roll-forward recovery.
* Bounded fingerprinted imports; changed-since-preview files are rejected.
* Saved-code requirement for passing reviews, explicit verbal assessment, cancellation,
  stable comparison baselines, submitted snapshots and explicit public review capture.
* Sync approval bound to commit refs; optional integrated catalog import.
* Readable terminal summaries and guided capture; JSON output remains machine-readable.
* Optional OpenAI adapter and restricted Linux Docker Python-script runner.
* Cached schema reflection, linear topic aggregation and unmeasured-time handling.
* Expanded regression/security tests and optional live sandbox CI job.

## 0.1.0 — unreleased

* Local JSON/TOML state, schema validation, OS locks, atomic snapshots and backups.
* Solution capture, metadata/README generation, multi-approach storage and import.
* Private recall sessions, deterministic scheduling, hints, mistakes and analytics.
* Owned-file Git commits, explicit safe sync and GitHub CLI authentication bridge.
* JSON/CSV/Markdown export, recovery, doctor and configuration.
* Optional installed scheduler/AI plugin contracts. AI disabled by default.
* Source execution explicitly unavailable; no unsafe runner fallback.
